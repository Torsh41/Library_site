# Unittests

Здесь пишутся юниттесты для тестирования функционала программы.
Пока что тесты разделяются на два раздела: `main` и `webapi`.

### `main`

Тесты, рассматривающие работу функционала системы напрямую.

### `webapi`

Тесты, рассматривающие работу функционала системы через HTTP POST и GET
запросы. Другими словами, эти тесты проверяют функционал, открытый пользователю.

### Запуск тестов

Перед запуском тестов, следует установить все необходимые зависимости
(содержимое python3, requiremebts.txt, sqlite3, и другие).

Далее следует перейти в корневую папку проекта, и из нее запустить одну из
следующих комманд:

```
python3 -m tests
docker exec -t lib-web python3 -m tests
```

Для запуска отдельно тестов `main` или `webapi`, можно указать вот такие
комманды:

```
python3 -m tests.webapi
docker exec -t lib-web python3 -m tests.webapi
```
